# Asset credits and permissions

This is an inventory to help review attribution and publishing rights. A
listing here is **not** evidence that permission has been granted. Record the
source, rights holder, licence or permission, permitted use, and any required
credit for each asset before sharing a build. Keep private permission records
outside the public repository when appropriate.
