# Contributing

This is a personal birthday project. Suggestions and bug reports are welcome,
but changes are accepted at the maintainer's discretion.

Before submitting a significant change, open an issue to discuss it. Do not
include personal information or secrets in issues, pull requests or commits.

## Develop and check

Follow the [quickstart](README.md#quickstart) to set up the game, then run:

```sh
npm test
npm run lint
npm run build
```

For visual or interaction changes, also check the game in a browser. The
[project guide](docs/PROJECT.md) describes the architecture, saves and
additional testing considerations.

## Rights and assets

The project's original materials are **all rights reserved**; see
[LICENSE](LICENSE). Before submitting code or other material, discuss its
licensing terms with the maintainer and make sure you have the right to
submit it.

Do not add music, artwork, fonts or other third-party material unless the
necessary permissions for the intended use and distribution are in place.
Document the source, applicable licence and required attribution in the
[asset inventory](docs/ASSET-CREDITS.md). Do not assume that existing assets
are cleared for redistribution.
